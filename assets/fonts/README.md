# Self-hosted website fonts

These font files are served directly by ItziGroup so a page visit does not require a Google Fonts request.

- `outfit-latin.woff2` and `outfit-latin-ext.woff2`: Outfit variable font, weights 300–900.
- `jetbrains-mono-latin.woff2`: JetBrains Mono variable font, weights 400–600.

The files came from the Google Fonts distribution and are redistributed under the included SIL Open Font License files. Keep the relevant license file whenever a font is copied or redistributed.
